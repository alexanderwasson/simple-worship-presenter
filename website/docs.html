How to use Simple Worship Presenter.

The workspace is divided into a library, a song library, a media library, the presentation editor and the audience display.

The weekly workflow

  1. Write or import the songs in the Songs library, splitting lyrics into labelled sections.
  2. Generate slides from a song. Choose how many lyric lines appear per slide.
  3. Build the service plan and add the presentations in order.
  4. Open the audience display on the projector and walk the plan from the control window.

Service plans

A service plan groups presentations into a running order for a date. Removing a presentation from a plan never deletes the presentation itself.

  • Create a plan from File → New service plan or the library button.
  • Add presentations and reorder them with the arrow buttons — the running order is saved exactly as shown.
  • Add an optional note for the team.
  • Save & present saves the plan, opens the audience display and starts the plan from item one.
  • Once a plan is live, the editor shows the running order with the current item marked LIVE. Jump to any item, or use Previous item / Next item.
  • Advancing past the last slide of an item moves to the first slide of the next item, so a whole service can be walked with Space.
  • Duplicate a plan to reuse it for the following week.

Songs

Each song stores title, artist, author, copyright, CCLI number, tags and an ordered list of sections. Sections are labelled however you like — Verse 1, Chorus, Bridge, Ending, Tag.

  • Reorder sections with the arrow buttons.
  • Repeat a section by generating from a custom order.
  • Generate slides creates a new presentation from the lyrics at four lines per slide.
  • Deleting a song never touches presentations already built from it.

Media

Upload PNG, JPG, GIF, WebP images plus MP4 video and MP3/WAV/OGG audio. Files are validated by their actual content, not just the extension.

  • Use Set as background to apply an image to the current presentation.
  • Deleting media releases the storage it used against your quota.
  • Only you can see your media; every request is checked against your account.

Scripture

The World English Bible is built in — all 66 books, 1,189 chapters. It is public domain and is stored once for the whole installation, so it never counts against your storage allowance and looking up a passage makes no external request.

  • Look up a passage by reference: John 3:16, Psalm 23, 1 Cor 13:4-7, Gen 1:1-2:3.
  • Search the whole translation by word or phrase.
  • Generate slides from a passage with your own line count, optional verse numbers and a reference label. A verse is never split across slides and the wording is never trimmed to fit.

Importing and backing up

Use File → Import backup… or the ⇧ Import backup button in the library. It accepts a converted backup (swp-import.json) or a package archive that bundles the manifest with its media/ folder.

  • Songs, presentations and service plans are all created — not just slide text.
  • Service plans are matched to the presentations that came with them.
  • When it finishes you see exactly what was created, plus anything skipped and why.
  • Media that is not bundled with the package is reported rather than failing the whole import.
  • Importing twice creates a second copy. It never overwrites what you already have.

Backing up is the reverse: administrators can download the database from Settings. Keep a copy somewhere safe.

Storage

Everything an account stores counts against its allowance: presentations, service plans, songs and uploaded media. Scripture does not count. The meter in the sidebar shows the total live.

  • Hosted accounts start with 25 MB. An administrator can raise or lower any account.
  • On your own server, set the starting allowance with DEFAULT_QUOTA_BYTES.
  • Deleting a presentation, plan, song or file releases its storage immediately.

Backgrounds and animation

Any image or video in your media library can become a background — for a single slide, or for a whole presentation so every slide shares it.

  • 🎞 Animated background in the slide panel picks a video or animated image. It plays silently and loops.
  • Overlay darkens the background so text stays readable over bright footage.
  • Remove a background and the underlying media file stays in your library.
  • Each slide also has an Animation — none, fade, rise, blur, scale, or word by word — which replays whenever the slide is shown.
  • Everything you set here is saved with the slide and follows you to the projector. Anyone with reduced motion enabled sees a still frame instead.

The audience display

Choose Tools → Audience display or the Live button. A separate window opens for the projector.

  • The control window drives it live: every slide selection is mirrored immediately.
  • Blank turns the display black without losing your place.
  • F toggles fullscreen on the display.
  • Drag the window to the projector first, then press F. Browsers cannot choose a physical monitor for you.

Search

Every collection has its own search box — presentations, service plans, songs, media and the slide list. Searches match titles, lyrics, notes, credits and file names as you type.

  • Press Ctrl + K anywhere in the workspace to open the global search.
  • Global search covers presentations, songs, service plans and media at once.
  • Choose a result to jump straight to it.
  • Esc clears the results.

Typography

Each slide carries its own text formatting, so a title slide and a lyric slide can look different inside the same presentation.

  • 14 font families: Manrope, Inter, Montserrat, Poppins, Source Sans 3, Oswald, Bebas Neue, Georgia, Playfair Display, Lora, Merriweather, Libre Baskerville, Roboto Slab and DM Mono.
  • Text size from 18 to 160 points, scaled proportionally so the editor and the projector match.
  • Weight toggle for regular or bold.
  • Text colour with a colour picker.
  • Horizontal alignment: left, centre or right.
  • Vertical position: top, middle or bottom of the slide.
  • Animation when the slide appears: none, fade, rise, blur in, scale up, or word by word.

Formatting is saved with the slide and travels to the audience display automatically. Animations replay each time a slide is shown, and are disabled automatically for anyone with reduced motion enabled at the operating system level.

Mobile remote

Control the service from a phone without touching the presentation computer.

  • On the presentation computer choose Tools → Connect Mobile Remote.
  • Scan the QR code with the phone camera, or open the shown link and type the pairing code.
  • The phone shows the current and next slide, and large Previous / Next buttons.
  • Tap any slide in the list to jump straight to it.
  • Black screen blanks the projector without losing your place; Restore output brings it back.
  • Several phones can be paired at once, and each can be disconnected individually from the same dialog.

Pairing codes expire after a few minutes and can be used once. The QR code contains only that short code — never your account credentials. Access can be revoked at any time.

If the site is served through a reverse proxy, the proxy must allow WebSocket upgrades. See DEPLOYMENT.md for the nginx configuration. Where WebSockets are blocked the remote falls back to ordinary HTTPS automatically.

Content and licensing

Simple Worship Presenter does not include any copyrighted song lyrics or Bible translations. Bring content you own or are licensed to use, and record your CCLI licence in Settings so it can appear in the presentation footer.
