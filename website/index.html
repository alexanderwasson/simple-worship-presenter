What it does

Everything a Sunday needs, nothing it doesn't.

Organise songs with proper verse and chorus sections, build a service plan for the day, and send lyrics to a second screen with one keystroke.

▤

Service plans

Group presentations into a plan with a date and notes. Launch the whole plan straight into presenter mode and walk it in order.

♪

Song library

Store songs with author, copyright and CCLI details. Split lyrics into labelled sections and generate correctly spaced slides automatically.

▧

Media library

Upload images, video and audio. Use any image as a slide or presentation background without re-uploading it every week.

▷

Live presenter

A separate audience window that follows the operator live. Blank the screen, jump to any slide, and go fullscreen on the projector.

⚙

Self-hosted

One Node.js process and a data folder. No external service, no account with us, no API key. Your server keeps everything.

✓

Clear licensing

Add your church CCLI licence to the workspace. Bring your own content and the rights to use it — we never ship copyrighted lyrics.

Self-hosting

Your church, your server, your data.

1

Install

Clone the project, run npm ci, and copy the example environment file.

2

Configure

Set a session secret, a persistent data directory, and the storage quota for your accounts.

3

Create your administrator

Open the site once and complete the first-run setup. Then add your team's accounts.

4

Present

Point a reverse proxy at it for HTTPS and use any modern browser on the control laptop and projector.

# install git clone https://github.com/alexanderwasson/simple-worship-presenter cd simple-worship-presenter npm ci # configure cp .env.example .env # edit SESSION_SECRET and DATA_DIR # run npm start
